# Batch 3: Criteria 6, 7, 8

## CRITERION 6: REGISTER
### Successful registration
```
rm -f /tmp/qa_jar
CSRF=$(curl -s -c /tmp/qa_jar http://127.0.0.1:8000/register | grep -oP 'name="csrf_token" value="\K[^"]+')
CSRF=eed6fd3c8b301e01a6cdacd1daed6dd004a4a7b30d1c4603e980af3e6fe3b5f4

curl -s -c /tmp/qa_jar -b /tmp/qa_jar -w "\nHTTP_CODE=%{http_code}\nREDIRECT=%{redirect_url}" -X POST \
  -d "username=e2e_user&email=e2e_user@example.com&password=QaPass123&confirm_password=QaPass123&csrf_token=$CSRF" \
  http://127.0.0.1:8000/register
HTTP_CODE=307
REDIRECT=http://127.0.0.1:8000/login
```
NOTE: email=e2e_user@test.local was rejected with "Invalid email address" (email validator rejects .local TLD). Used e2e_user@example.com instead.

### Duplicate username
```
CSRF2=$(curl -s -c /tmp/qa_jar http://127.0.0.1:8000/register | grep -oP 'name="csrf_token" value="\K[^"]+')
curl -s -c /tmp/qa_jar -b /tmp/qa_jar -w "\nHTTP_CODE=%{http_code}" -X POST \
  -d "username=e2e_user&email=other@example.com&password=QaPass123&confirm_password=QaPass123&csrf_token=$CSRF2" \
  http://127.0.0.1:8000/register | grep -oP "(That username is taken[^<]*|Fields must match[^<]*|HTTP_CODE=\d+)"
That username is taken. Please choose a different one.
HTTP_CODE=200
```

### Invalid passwords (mismatch)
```
CSRF3=$(curl -s -c /tmp/qa_jar http://127.0.0.1:8000/register | grep -oP 'name="csrf_token" value="\K[^"]+')
curl -s -c /tmp/qa_jar -b /tmp/qa_jar -w "\nHTTP_CODE=%{http_code}" -X POST \
  -d "username=e2e_bad&email=bad@example.com&password=QaPass123&confirm_password=DIFFERENT&csrf_token=$CSRF3" \
  http://127.0.0.1:8000/register | grep -oP "(That username is taken[^<]*|Fields must match[^<]*|HTTP_CODE=\d+)"
Fields must match.
HTTP_CODE=200
```

## CRITERION 7: LOGIN / ACCOUNT / LOGOUT
### Login
```
rm -f /tmp/qa_jar
CSRF=$(curl -s -c /tmp/qa_jar http://127.0.0.1:8000/login | grep -oP 'name="csrf_token" value="\K[^"]+')
CSRF=948d5b704e5c38a6a4b9cf256961fc05206961ca3cf3c4989a2108901c0b75f6

curl -s -c /tmp/qa_jar -b /tmp/qa_jar -w "\nHTTP_CODE=%{http_code}\nREDIRECT=%{redirect_url}" -X POST \
  -d "email=e2e_user@example.com&password=QaPass123&csrf_token=$CSRF" http://127.0.0.1:8000/login
HTTP_CODE=307
REDIRECT=http://127.0.0.1:8000/art_home
```

### Account
```

### Logout

### Account after logout
```
curl -s -b /tmp/qa_jar -c /tmp/qa_jar -w "\nHTTP_CODE=%{http_code}\nREDIRECT=%{redirect_url}" http://127.0.0.1:8000/account
