# Задания нет

Здесь живёт **текущее задание** команды агентов. Сейчас его нет.

Положите в этот файл новое задание в формате: суть, что сделать, вне рамок, критерии
успеха (каждый — с конкретной командой проверки), финальные критерии. Затем запустите
Qwen Code в корне проекта и скажите:

> Выполни текущее задание из tasks/current/REQUIREMENTS.md и не останавливайся,
> пока все критерии успеха не будут подтверждены доказательствами.

Правила команды — в [AGENTS.md](../../AGENTS.md), инструкции оркестратора — в
[QWEN.md](../../QWEN.md). Закрытые задания с отчётами лежат в `tasks/NNN-<slug>/`.

> В файле REQUIREMENTS.md всегда будет какое-нибудь новое задание. После выполнения
> задание заменяется и продолжается командное выполнение нового.
